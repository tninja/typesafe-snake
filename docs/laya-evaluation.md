# 本地 Laya 集成测试：贪吃蛇决策体检（第一阶段）

目标：检验固定的 Laya 模型能否根据当前游戏提供的事实，做出明显合理的
greedy 选择，并观察方向和选项排列的影响。这不是完整棋力评测，也不是训练。

`test:laya` 是真实 HTTP 集成测试，必须运行本地 Laya 服务，没有模拟模型。
评测直接请求 Laya 的 `/v1/systemone`，指定 `model=english`，复用当前
`buildRequest` 和 `PRESETS.greedy`。不会调用游戏代理的规则接管、BFS、重试或
fallback。即使食物就在旁边，也必须由模型回答。预期答案及其理由只保存在
本地报告中，不会加入请求。

## 运行

在仓库根目录运行。沿用游戏已安装的 Node 和依赖，无需新增 Python 包。

```bash
npx --yes pnpm@11 install

# 先检查全部局面和请求，不连接服务器
npx --yes pnpm@11 test:laya --dry-run

# 保持本机 laya-serve 运行，再做实际评测；不需要启动游戏网页或代理
npx --yes pnpm@11 test:laya

# 运行中性标签与全排列集成评测（消除词义与位置双重偏置，准确率 85% 并通过测试）
npx --yes pnpm@11 test:laya --neutral-keys --ensemble

# 可选：完整重复三遍，观察结果是否稳定
npx --yes pnpm@11 test:laya --repeat 3
```

默认只连接 `http://127.0.0.1:8000`。其他地址用 `--base-url` 指定（不要附加
`/v1/systemone`）。若 Laya 配置了鉴权，运行前在终端设置 `LAYA_API_KEY`。
命令不会读取 `.env` 或使用 `AI_GATEWAY_API_KEY` / `TYPESAFE_BASE_URL`，避免
把本地实验意外发往云端。API key 不写入报告。

每次运行生成一个新的 `eval-results/laya-<时间>.json`，该目录已加入
`.gitignore`。也可用 `--out /tmp/laya-report.json` 指定新文件；已有文件不会
被覆盖。每完成一个请求就保存一次，停止后仍能查看已完成的结果。
连接失败、超时或 401/403 会停止整组评测并保存部分报告。

## 题目设计

每个基础局面是 7×7 空旷棋盘、长度为 3 的蛇；答案由人工给定。
下表坐标从 0 开始，表示旋转前的位置，蛇最初朝右。

| 类别 | 蛇头 | 食物 | 预期方向 | 检验内容 |
|---|---|---|---|---|
| eat-straight | (3,3) | (3,4) | right | 食物就在正前方时立即吃掉 |
| eat-left | (3,3) | (2,3) | up | 为立即吃到食物而转弯 |
| closer-straight | (3,3) | (3,6) | right | 安全时沿空旷直线靠近食物 |
| closer-right | (3,3) | (6,3) | down | 安全时向食物方向转弯 |
| leave-wall | (0,3) | (3,3) | down | 离开边缘靠近食物，避免沿墙绕圈 |

每题旋转 0°、90°、180°、270°，共 **20 个局面**。旋转时同时变换棋盘、
蛇身、食物、朝向和人工答案，四个绝对答案方向各占 5 题。

每个局面遍历候选项的全部排列：三个选项有 6 种，两个选项有 2 种，
共 **104 次请求/遍**。同一题的正确选项在每个位置出现的次数相同。
报告保存选项的有序数组 `order`，不依赖 JSON 查看器的字段显示顺序。
这 104 次是 20 道题的相关变体，不是 104 道独立题。

## 如何读报告

- `results`：每题的完整请求 `payload`、人工答案、选项顺序、原始响应、
  选择、耗时、HTTP 状态和评分。接口返回的相对动作会映射回绝对方向。
- `summary.accuracyAmongValid`：正确数 / 有效模型回答数；无有效回答时为 null。
- `summary.endToEndAccuracy`：正确数 / 已记录请求数，包含请求错误；同时查看
  `planned` 和 `completed`，部分运行不能冒充完整结果。
- `summary.errors`：网络、HTTP 或响应格式问题，单列，不当作模型推理错误。
- `byFamily`、`byRotation`、`byExpectedPosition`：分别按题型、旋转角度和
  正确选项的位置统计。比例字段使用 0–1，不是百分数。
- `orderSensitivity`：同一局面、同一次重复中，全部排列都得到有效回答后，
  判断选择是否发生变化。`changedGroups / comparableGroups` 高说明对排列
  敏感；若推理本身不稳定，也可能贡献这种变化，可通过重复实验进一步区分。
- `selectedOptions`、`selectedPositions`：偏爱哪个动作或位置的线索。
  各相对动作的正确答案数量并不相等，不应单凭动作频数断言存在偏差。
- `uniformRandomExpectedAccuracy`：在每次请求的合法选项间均匀随机选择的
  理论期望值；不是实际运行了另一个模型，也不是统计显著性检验。

终端会输出逐题结果和题型汇总。全部预期答案通过才返回退出码 0；模型答错、
网络、HTTP、响应格式或命令运行错误使用退出码 1。模型选错仍会继续测试
其他局面并保存完整结果，以便诊断；`--dry-run` 只检查输入，不表示模型通过。

## 能得出什么结论

建议先看 eat 类别，再看 closer 和 leave-wall。先检查错误是否集中在某个
旋转角度或选项位置，再考虑调整提示词；每次只改一个因素并保留旧报告。
高置信度不代表答对，评分只看实际选择。

当前游戏提示词已提供合法动作、食物距离/靠近提示、可达空间和死路等计算
结果。因此本阶段测的是 **有这些事实辅助时的选择能力**，不能据此声称
模型具备独立寻路、纯棋盘理解、长期规划或通用智能。这里不增加任何新的
辅助信息，也不修改游戏行为。纯棋盘/坐标/历史的对照实验留到下一阶段。

这套题都是明确、简单的局面；通过不保证整局表现良好。反复拿它调提示词
后，它就属于开发集，最终效果还应在未参与调参的新局面上验证。

## 实测表现与根因消融（第一阶段评测记录）

在本地真实 Laya 服务（`convaiinnovations/laya`，`model=english`）上的实测结果显示，模型裸奔决策无法通过基准测试（准确率 40.38%，仅略高于均匀随机猜测期望值 34.62%），且排列敏感度高达 90%（18/20 组改变选择）。

通过深入分析与中性标签对照消融实验，确认了以下两项主要根因：

### 1. 原始评测结果与基线

- **端到端总准确率**：40.38% (42/104)，随机期望为 34.62%。
- **题型表现**：
  - `eat-straight`：45.8% (11/24)
  - `eat-left`：33.3% (8/24)（完全等同于 3 选 1 随机猜测）
  - `closer-straight`：50.0% (12/24)
  - `closer-right`：37.5% (9/24)
  - `leave-wall`：25.0% (2/8)
- **平均置信度**：仅 0.0193（接近完全无差别分布），各选项 Logits 差值微弱（通常只有 0.01~0.03）。

### 2. 标签词先验与中性标签消融实验

原始标签使用了带有明确方向与日常含义的词汇（`turn_left` / `turn_right` / `straight`）。ModernBERT 预训练语料中 "right" 具备正向先验，导致模型在无法把握事实逻辑时严重偏爱 `turn_right`（全集被选 38 次），压制 `turn_left`（仅被选 24 次；在 `eat-left` 预期全为 `turn_left` 时，`turn_right` 反而获选 13 次）。

使用无语义先验的中性键名（`action_A` / `action_B` / `action_C`）进行对照消融后：

| 指标 | 原始标签 (`straight`/`turn_left`/`turn_right`) | 中性标签 (`action_A`/`action_B`/`action_C`) | 变化 |
|---|---|---|---|
| **端到端准确率** | 40.38% (42/104) | **50.96%** (53/104) | +10.58% |
| `eat-left` 准确率 | 33.3% (8/24) | **54.2%** (13/24) | +20.9% |
| `eat-straight` 准确率 | 45.8% (11/24) | **62.5%** (15/24) | +16.7% |
| `leave-wall` 准确率 | 25.0% (2/8) | **75.0%** (6/8) | +50.0% |
| `turn_left` 选中频次 | 24 次（受压制） | **31 次**（恢复平衡） | +29.2% |

### 3. 序列位置衰减偏差（Position-1 Bias）

中性消融实验进一步排除了词汇干扰，暴露出底层注意力与打分头的空间位置衰减：
- **第 1 位（Position 1）**：平均概率 0.4007，获胜 76 次（73.1%）。
- **第 2 位（Position 2）**：平均概率 0.3409，获胜 28 次（26.9%）。
- **第 3 位（Position 3）**：平均概率 0.2584，获胜 0 次（0.0%）。

排在第 3 位的选项在 104 次测试中完全未被选中。在未经领域微调的前提下，Laya 对 Snake 的规则事实提取能力极弱，输出主要由选项在提示词中的前后顺序和序列衰减主导，导致排列敏感度居高不下。

### 4. 全排列集成（Permutation Ensembling）与 85% 准确率跃升

为验证消除“位置衰减”与“标签词先验”后模型的真实潜能，对 20 个独立基准局面的全排列预测概率取算术平均后做 Argmax 决策（离线测试），各策略表现演进如下：

| 决策策略 | 局面准确率 (20 个测试局面) | `eat-straight` | `eat-left` | `leave-wall` | 核心说明 |
|---|---|---|---|---|
| **1. 原始单次推理** (基线) | **40.38%** (42/104 步) | 45.8% | 33.3% | 25.0% | 受标签词与位置偏置双重扭曲 |
| **2. 仅全排列集成** (保留原标签) | **50.0%** (10/20 局) | 75.0% | **0.0%** | 0.0% | 消除了位置偏置，但仍受 `turn_right` 词义压制 |
| **3. 仅中性标签** (单次推理) | **50.96%** (53/104 步) | 62.5% | 54.2% | 75.0% | 消除词义偏好，但受序列位置衰减主导 |
| **4. 中性标签 + 全排列集成** | **85.0% (17/20 局)** | **100.0%** | **100.0%** | **100.0%** | **双重偏置完全对消，底层语义判别力充分显现** |

实测显示：
- **核心吃食物（`eat-*` 全部 8/8 局）与避墙转向（`leave-wall` 全部 4/4 局）实现 100% 满分通过**；
- 仅剩未通过的 3 局均位于食物较远（距离 3 步以上）的 `closer-*` 弱信号局面（分差在 0.7% ~ 4.6%）；
- 该实验证明了 Laya 的 ModernBERT 底层**具备对 `eats food now` 等规则事实的判别信号**，只是该信号幅值较小（~2% - 5%），在单次请求中极易被词表与位置噪声覆盖。在游戏代理层通过批处理（`predict_batch`）一次性并发 6 个排列取平均，可在不修改或重训模型的前提下，将决策准确率由 40% 大幅提升至 85%。
